# ASIQ ARENA — оқу тренажёры «Асық ату»

Версия 1.0: этапы 1–5 ТЗ. Пять уроков по модели 5ҚАДАМ, свободная тренировка, сайыс двух учеников, достижения, режим интерактивной панели, офлайн-режим (PWA).

Стек: React 18 + TypeScript + Vite 5, Three.js через React Three Fiber, физика Rapier (@react-three/rapier).
Без сервера, регистрации, баз данных, камеры и платных API. Прогресс — localStorage этого браузера.

## Запуск на компьютере

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build      # проверка типов + production-сборка в папку dist/
npm run preview    # просмотр готовой сборки: http://localhost:4173
```

Готовая сборка `dist/` уже лежит в архиве — её можно открыть через любой статический сервер
(двойной щелчок по index.html не подойдёт: браузер блокирует модули с file://).

## Публикация на Vercel

1. Загрузите папку проекта (без node_modules) в репозиторий GitHub.
2. На vercel.com: Add New → Project → выберите репозиторий.
3. Framework Preset: **Vite** (определится сам). Build Command: `npm run build`. Output Directory: `dist`.
4. Deploy. Переменные окружения не нужны.

Альтернатива без GitHub: `npx vercel` в папке проекта, затем `npx vercel --prod`.

## Офлайн (PWA)

Обычная сборка (`npm run build`) создаёт service worker и манифест. После первого открытия сайта с интернетом
приложение работает без сети и может быть установлено на главный экран Android («Добавить на главный экран»).
Проверено: после первой загрузки и отключения сети приложение открывается и 3D-поле работает.
Шрифты Google кешируются при первом онлайн-открытии; без них используется системный шрифт.

## Правила засчитывания (учебные, показываются ученику в каждом уроке)

| Урок | Бросков | Правило |
| --- | --- | --- |
| 1. Асықпен танысу | 3 | контакт сақа с нысаной |
| 2. Дұрыс көздеу | 5 | контакт; нысана каждый раз в новом месте |
| 3. Ату дәлдігі | 10 | контакт; нысана на одном месте; 1–5 и 6–10 считаются отдельно |
| 4. Ара қашықтық | 9 | контакт И сақа остановился не дальше 1,5 м за нысаной; 3 дистанции по 3 броска |
| 5. Мергендік шеберлігі | 8 | контакт = 1 ұпай, нысана вышла из кольца (R = 0,6 м) = 2 ұпай |

Общее:

- Попадание = реальный физический контакт сақа с асыком-нысаной (есть сила контакта в Rapier).
  Событие «начало столкновения» не используется: оно может прийти от упреждающего контакта без касания.
- Сдвиг нысаны не обязателен; если она не сдвинулась больше чем на 5 см, это сообщается отдельно.
- Совет после промаха строится по фактической траектории: боковое отклонение → совет по направлению;
  не долетел → увеличить силу; пролетел над нысаной → уменьшить силу; иначе — только наблюдаемый факт.

Масштаб, расстояния и физические коэффициенты — учебные упрощения, а не модель реального броска.

## Один файл для быстрого просмотра

`npm run build:single` собирает всё приложение в один файл `dist-single/index.html`.
Его можно открыть двойным щелчком в Chrome/Edge без сервера (нужен для показа на компьютере или панели без интернета).
